# japan_wip (archived)

Work-in-progress variants of the chugoku, kyushu, and shikoku scrapers, moved here from `src/scrapers/japan_wip/` during the July 2026 repo cleanup. The production versions live in `src/scrapers/japan/` and are the ones registered in `airflow/config/scraper_registry.yaml`.

Sample processed output JSONs that were previously committed under `chugoku/processed/` were removed; they remain available in git history if needed.
